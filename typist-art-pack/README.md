# Typist 太空打字防御战 — 美术概念包 V0.1

## 内容
- `concepts/art-direction.png`：统一美术方向与视觉元素参考
- `concepts/asset-overview.png`：玩家、四类敌机、攻击、爆炸、UI、背景的素材清单概念图

## 注意
这两张是**概念拼版**，不是已经切分、透明、可直接投入游戏的 PNG 精灵素材。拼版中的旋转帧、受损帧与爆炸帧只是视觉示意，不能视为完整连续动画。

## 正式素材要求
1. 玩家飞船与四类敌机分别导出独立透明 PNG，统一正上方朝向、俯视角、比例和光源。
2. 不要在飞船本体绘制汉字、词组、血条或 HUD；由 Vue/Canvas 在运行时绘制文字与状态。
3. 全息核心底座、边框、血条、弹道、命中火花、爆炸帧与背景均独立分层。
4. 玩家飞船的转向优先由引擎旋转精灵实现，不必提前绘制 16/24 个方向图。
5. 验收包括透明边缘、中心锚点、缩小后的文字可读性、动画连贯性和性能。
