# 动画与打击反馈规范

## 事件序列
`提交正确编码` → `立即判定目标与伤害` → `飞船朝目标平滑转向` + `炮口闪光` → `可见弹道` → `命中火花/受损或爆炸` → `浮动得分/弹药奖励`。

## 重要约束
- 逻辑结算不依赖动画结束；玩家可以连续提交编码，多个射击事件可以同时在画面中存在。
- 视觉弹道必须飞向提交时选定的目标或其合理的命中位置，避免目标已死导致子弹错误跳转。
- 同一敌机 HP 的减少、受损状态与爆炸状态必须一致；不允许死亡后重复计分或重复发放奖励。
- 汉字投影始终正向；命中时可短暂闪亮，但不能长时间失去可读性。

## 推荐动效（时间仅为试玩起点）
| 动效 | 建议时间 | 视觉要点 |
|---|---:|---|
| 转向 | 80–180 ms | 平滑追向目标，不阻塞发射 |
| 炮口闪光 | 40–80 ms | 蓝白闪光、轻微后坐力 |
| 普通弹飞行 | 100–250 ms | 蓝白弹体、短尾迹 |
| 穿甲弹飞行 | 100–250 ms | 青绿光束、强尾迹 |
| 命中火花 | 80–160 ms | 局部火花与闪白 |
| 轻型爆炸 | 250–450 ms | 核心闪光、火球与碎片 |
| 重型爆炸 | 400–700 ms | 多层冲击波、碎片、烟雾 |

以上均为建议值，不是锁定的美术参数。

## 状态优先级
存活 → 受损 → 致命击毁 → 爆炸中 → 清理。爆炸中的敌机不再作为可攻击目标（建议，需与输入规则确认）。

## 性能降级
- 粒子池化，限制同屏数量与尾迹长度；背景视差和烟雾优先降级。
- 暂停时动画时间冻结，恢复时平滑继续。
- 关键伤害、得分、输入反馈不依赖音效/粒子是否加载成功。
