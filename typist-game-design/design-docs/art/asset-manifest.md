# 游戏素材清单与交付要求

## 素材生产原则
先统一概念设定，再生产可复用、透明背景、独立分层的正式素材；不要把带 UI/文字/背景的整张游戏概念图直接裁切为精灵。

| 优先级 | 资产 | 建议数量 | 交付要求 |
|---|---|---:|---|
| P0 | 玩家飞船 | 1 款 | 正俯视、朝上、透明 PNG、无文字；中心锚点明确 |
| P0 | 敌方轻型侦察机 | 1 款 | 1 HP，暗红，透明 PNG，核心预留区 |
| P0 | 敌方装甲战斗机 | 1 款 | 2 HP，紫灰，透明 PNG，核心预留区 |
| P0 | 敌方重型轰炸机 | 1 款 | 3 HP，橙黑，透明 PNG，核心预留区 |
| P0 | 高速奖励机 | 1 款 | 1 HP，绿色识别光效，透明 PNG |
| P0 | 太空背景 | 1 张 | 无飞船/文字/UI，可裁切与平铺 |
| P0 | HUD 基础元素 | 1 组 | HP 格、弹药、暂停、计时等，可优先程序绘制 |
| P1 | 普通弹与穿甲弹 | 各 1 组 | 透明图层或程序绘制方案，区分明显 |
| P1 | 命中火花 | 1 组 | 透明序列帧或粒子参数 |
| P1 | 轻/重爆炸 | 各 1 组 | 透明序列帧/粒子参数，帧率统一 |
| P1 | 受损/烟雾 | 2–3 组 | 可叠加、与机型兼容 |
| P2 | 额外星云、残骸、空间站 | 若干 | 背景装饰，不影响可读性 |

## 资产技术规范（建议，最终由实现验证）
- PNG 使用 alpha 透明，避免不透明背景、投影底板、文字或 UI 混入飞船图层。
- 统一朝向：船头朝上；旋转中心以船体几何中心或统一锚点为准。
- 导出分辨率优先使用实际显示尺寸的 2 倍，以便高 DPI 缩放；最终数值待窗口测量后确定。
- 文件命名可采用 `player_idle.png`、`enemy_scout.png`、`enemy_armored.png`、`enemy_heavy.png`、`enemy_reward.png`；最终以仓库现有命名约定为准。
- 保留原始生成图和最终裁切图的来源记录，检查边缘 alpha、光晕、统一尺度、素材授权。
- 中文文本与词组必须由运行时字体渲染，**不能烧录在图片上**。

## 验收
- 5 款飞船可独立放到任意深色背景上，轮廓完整、无 UI 残留。
- 同一敌机可展示不同单字和词组，无需重新生成图片。
- 多敌机同时出现时，文字与 HP 条不严重互相遮挡。
- 低特效/缺失素材时仍能以占位资源正常游戏。
