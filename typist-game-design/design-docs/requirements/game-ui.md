# 游戏界面与交互

## 总体布局
- 保留现有 Typist 桌面应用整体框架、游戏入口和设置体系；游戏内容区替换为深色太空战场。
- 顶部 HUD：模式/剩余时间、耐久、连击、得分、速度、准确率、暂停；应适配现有窗口尺寸。
- 中央战场：不同机型敌机从上方出现并下落，文字投影覆盖机身核心；玩家飞船固定在底部中央，围绕中心旋转瞄准。
- 底部 HUD：穿甲弹库存、当前输入编码反馈（如需要）、简洁状态提示。**取消固定「当前目标」展示**。
- 文字标签不直接烧录在飞船图片中；应在运行时动态渲染，支持 1–4 汉字及更多词组显示的布局扩展。

## 信息层级
1. 敌机文字/词组（最高优先级，清晰且不旋转）
2. 敌机接近防线的危险程度、血量
3. 玩家输入反馈、弹药/耐久
4. 子弹与爆炸
5. 星空、星云和装饰性场景

## 状态
- 待开始、准备倒计时（如原游戏已有）、运行、暂停、结算。
- 暂停应停止游戏逻辑与战场动画推进；恢复时不应瞬移或补算大量帧。
- 输入错误用轻量反馈，不用遮挡全屏的警告。
- 词组显示区域可横向扩展，不能因此强制扩大敌机实体尺寸。

## 可用性
- 高 DPI 和窗口缩放下文字清晰，血量状态可辨识。
- 降低屏幕闪烁；支持减少粒子/震动的质量选项（可后续实现）。
- 暗色战场与 Typist 原有浅色/深色主题应协调；外围 UI 继续使用既有主题变量。
- 不把关键状态仅依赖颜色表达，至少同时提供血格/图标/文字。
