# 练习需求

更新时间：2026-10-30。状态：以下规则已确认；待定细节见 [问题记录](../state/issues.md)。尚未实现或验收。

## 1. 课程与输入判定

- 提供一级至四级简码及词组课程，支持切换课程；另提供生词专项练习。
- 各分类课程使用内置词库与对应分类的补充词库合并后的内容，补充条目也参与练习；见 [补充词库需求](supplemental-dictionary.md)。
- 用户通过系统输入法输入文字，应用按最终提交的文字判定；文字与题目完全相同即正确。
- 不限制用户实际使用的编码。此规则取代讨论早期的“只接受当前课程编码”和由应用按原始编码判定的设想。
- 没有产生文字且未提交空格时，不进入下一题。
- 应用收到直接输入的空格时，视为跳过，记录错误并进入下一题；不另设跳过操作。
- 输入法选字所使用的空格不应被重复识别为跳过；两平台实际输入行为待验证。
- 退格仅允许修改未提交的内容，不允许修改已判定的答案。

### 输入提交边界（已确认）

- 一次输入法最终提交作为一次完整答案；组合编码、选择候选词期间不判定，不将组合过程或选字按键重复计为作答。
- 词组必须一次完整提交，不逐字累积。例如题目为“学习”，提交“学习”正确；单独提交“学”或提交“学习方法”均整体判错并进入下一题。
- 一次提交不拆成多道题答案，即使内容与连续题目的拼接相同。
- 实际提交的英文、数字、标点按普通错误答案处理；输入法选字使用的数字、空格等按键，未实际提交这些字符时不计作答。
- 作答区域不接受粘贴：不改变题目、作答结果或统计，简短提示“请使用输入法作答”。托盘生词添加文本框仍正常接受粘贴。
- 直接提交空格仍沿用本节跳过规则；无提交不判定。

## 2. 分级练习反馈

- 上方按顺序显示一排文字或词组，下方按题目位置对齐显示用户提交的文字。
- 答对时，下方显示与题目一致的绿色文字，不展示正确编码。
- 答错时，下方显示红色的用户输入文字；对应上方题目下方显示该题的正确编码，随后继续下一题。
- 跳过或没有对应文字的错误结果，下方结果位置留空，仍显示正确编码。
- 错误后的编码提示使用该题在当前课程中的编码。
- 生词专项练习沿用本节反馈布局，答错时显示该文字全部对应编码。

## 3. 练习组与展示

- 练习组与一次显示的题目数量分开：一组题目可以分多排依次显示、循环练习。
- 一次显示多少题，根据窗口可用宽度和文字、词组长度自适应。
- 调整窗口只改变排版，不改变练习组内容或学习进度。
- 练习组默认 20 题，组大小可配置；课程内容不足组大小时使用全部内容。
- 初次组建练习组时，从尚未覆盖的课程内容中随机选题。
- 每轮练习组内每题出现一次，下一轮重新打乱顺序。
- 组大小允许 5～100 题，阈值允许 1～10 次，全课程共用设置；修改在下次开局生效，扩缩组和阈值变更处理见 [配置与会话规则](settings-and-session.md)。

## 4. 熟练、替换与覆盖

- 默认每题连续答对 3 次视为暂时熟练，连续答对次数阈值可配置。
- 答错或空格跳过，该题连续正确次数归零；暂不以答题速度作为熟练条件。
- 熟练题逐题退出当前练习组，替换在下一轮生效，不等待整组全部熟练。
- 有未覆盖内容时，补位约 80% 选择新题、20% 选择暂时熟练的复习题；某类不足时由另一类补足，未熟练的组内题目继续留组，不被挤走。
- 按课程累计补位名额，按 4 个新题、1 个复习题循环，不每轮独立取整；某类不足时由另一类补足。
- 复习候选优先按距离上次作答最久排序，其次累计错误较多优先，同条件随机。
- 复习题重新进入后，开始新一轮连续正确计数，达到配置阈值才退出；答错或跳过取消暂时熟练状态并将计数归零。
- 全部覆盖后不自动结束，继续至限时结束；补位优先选择尚未熟练且不在当前组内的题，其次选择熟练复习题。
- 可用题目不足组大小时缩小练习组，同一轮不重复出现同一文字。
- 保存各课程当前练习组、连续正确次数及覆盖与熟练情况，下次练习继续；限时结束不清空学习进度。
- 暂时熟练不等于永久掌握。
- 同一课程内按文字累计熟练度，不因同文字有多个编码重复练习；不同课程独立保存进度。生词专项练习沿用批次与替换规则。
- 补充词条变更时按最终课程归属更新练习组：退出课程的文字立即移除，当前题取消不计错，下一轮补位；清除其对应课程熟练记录，保留其他进度和已完成统计。空课程停止练习，详见 [补充词库关联规则](supplemental-dictionary.md)。

### 覆盖与进度展示

- 当前课程的文字实际作答一次即视为已覆盖，答错和空格跳过均计入覆盖；仅显示、未作答不计入。
- 分别展示“已练过 / 总题数”与“暂时熟练 / 总题数”，不将覆盖等同于熟练。
- 总题数按当前课程不同文字计，不按多编码组合数计；各课程独立统计，生词课程沿用同样规则。
- 暂时熟练不代表永久掌握；复习答错后，暂时熟练数量相应减少，已覆盖状态不撤销。
- 保存词库变更后同步更新覆盖统计：新增有效文字未覆盖，退出课程的文字从统计中移除，其他文字状态不变；新增内容下一轮补位进入练习。

## 5. 计时与暂停

- 支持 1～5 分钟练习。
- 点击开始后固定倒计时 3 秒，再正式计时。
- 允许主动暂停，暂停期间保留题目，停止计时与作答；切换窗口或最小化时自动暂停。
- 限时结束立即停止练习并显示本次成绩。
- 到时未提交内容不计成绩；无提交时正确率显示“—”，速度为 0。
- 暂停、手动恢复、中途结束、关闭到托盘及退出重启行为统一见 [配置与会话规则](settings-and-session.md)，不自动恢复未结束的一局。

## 单次统计口径（已确认）

- 速度＝正确字数 ÷ 有效练习分钟数，有效时间不含暂停。
- 正确率＝正确题数 ÷ 已答题数，空格跳过计为错误题。
- 一个词组按一题判定；答对后按词组字数累计正确字数。
- 同字多码的去重存储与按文字学习是不同规则，不将编码组合数作为同课程独立练习题数。

## 6. 后续验收检查点

以下为已确认行为对应的待执行检查，不代表验证通过：

- 相同文字由不同编码输入时均判正确；不同文字判错并推进。
- 输入法空格选字不会额外跳题；直接提交空格时记录一次错误并推进。
- 正误反馈、空结果和编码提示按上述规则显示，结果与题目位置对应。
- 窗口大小变化只影响排版；词组长度影响一次展示数量。
- 默认组大小为 20，默认阈值为连续正确 3 次，两者均可配置。
- 达到阈值、答错归零、下一轮替换及新题/复习混合补位行为符合规则。
- 再次练习时恢复对应课程学习进度；到时停止并显示成绩。
- 作答或跳过计入覆盖，仅显示不计；覆盖和暂时熟练分别展示。
- 复习按最久未作答、累计错误多的顺序选择；复习重新计数，答错取消暂时熟练状态。
- 全部覆盖后继续复习，内容不足缩小组，同轮不重复同文字。
- 组合输入不提前判定；词组一次完整提交，不累积单字或跨题拆分；实际提交的英文、数字、标点计错。
- 作答粘贴被忽略并提示，不推进题目、不改变成绩；托盘文本框粘贴不受影响。
