# 项目需求概览

更新时间：2026-10-30。状态：需求讨论中；各节按确认状态记录，不代表已实现。

## 已确认：定位与边界

- 技术栈为 Electron、Vue 3、TypeScript；具体架构与依赖版本见 [技术约束](../architecture/overview.md)，尚未完成选型。
- 从旧项目提取功能，重新开发面向五笔学习者的桌面练习工具，主要供个人使用。
- 支持 macOS 和 Windows 10；离线运行，数据保存在本机。
- 暂时仅支持五笔 86 版。
- 提供一级至四级简码、词组课程，以及个人生词专项练习。
- 支持 1～5 分钟限时练习，展示用时、速度、进度、正确率及本次结果；速度按正确字数与有效分钟计算，正确率按正确题数与已答题数计算。
- 分别展示已覆盖和暂时熟练进度，实际作答（含错误与跳过）计入覆盖；补位约 80% 新题、20% 复习，全部覆盖后继续复习至限时结束。
- 练习业务规则见 [练习需求](practice.md)。

## 已确认：生词本基础范围

- 支持从系统托盘打开小窗口，粘贴文本后手动点击添加；按词库最长词组优先、单字兜底识别，直接添加并去重，无需预览确认。
- 生词来自内置五类词库与补充词库的合并结果；保留对应的全部不同原编码，重复添加不重置学习进度。详细规则见 [生词添加需求](vocabulary-addition.md)。
- 支持按文字聚合查看全部编码、CSV 导出；托盘添加后展示本次新增文字及编码，不列出已有组合，点击继续添加显示下一批文本框。
- 生词支持单条与批量删除；生词专项练习沿用分级练习的批次、替换与反馈，错题提示全部对应编码。
- 设置中心分别支持生词本与补充词库 CSV 导入导出，不携带学习进度；统一按“文字＋编码”去重，完全相同则忽略，合并保留本地独有条目与已有学习进度。
- 生词添加与文件导入导出是独立流程；跨设备先导入补充词库，再导入生词本，生词条目严格匹配本机合并词库。详见 [导入导出需求](data-exchange.md)。

## 已确认：补充词库

- 设置中心支持逐条添加文字、编码及五类课程分类；统一按“文字＋编码”去重，同字异码可保留。
- 内置 `data` 保持原样，补充词库独立保存到本机用户数据目录，使用时合并读取。
- 补充条目用于托盘识别、生词取码及对应课程练习；见 [补充词库需求](supplemental-dictionary.md)。
- 托盘不提供未知词手填编码流程，严格匹配合并词库。
- 补充词条支持修改编码、分类及单条、批量删除；内置词库不允许修改。
- 变更后按最终词库同步移除失效的生词编码组合；退出课程的文字立即移出练习组并清除对应课程熟练记录，不回退已完成统计。修改作为完整变更判断，避免中间步骤误删。

## 已确认：打字游戏

- 独立的下落自由消除模式，覆盖五类与生词课程，游戏不改变普通练习进度。
- 落底循环不记漏题，消除后随机补题，屏幕同文字不重复；悬停可查看编码。
- 三档固定难度，支持 1～5 分钟与暂停；展示消除、字数、错误、正确率和速度，不设额外积分。
- 悬停暂停单个目标；内容不足时减少目标数量，无提交正确率显示“—”，到时未提交内容不计成绩。详见 [打字游戏需求](typing-game.md)。
- 普通练习与游戏均在切换窗口或最小化时自动暂停，暂停停止计时与作答，游戏同时停止移动。

## 已确认：配置与会话

- 设置中心统一配置组大小 5～100、连续正确阈值 1～10，默认 20 与 3，修改下次开局生效；开始前选择时长和游戏难度并记住上次选择，开始倒计时 3 秒。
- 暂停后手动继续，不再倒计时，未提交输入作废不计错；离开页面保持暂停，关闭主窗口收到托盘，重启只恢复学习进度。
- 中途结束展示实际成绩，切换课程、重新开始及退出应用按 [配置与会话规则](settings-and-session.md) 处理。

## 范围状态

- 旧项目的界面、按钮或未完成逻辑仅为背景，不视为本项目已交付功能。
- 首版不包含历史成绩趋势、排行榜、闯关、云同步及整套学习进度备份；仅保存本机学习进度，CSV 交换不携带进度。
- 生词同字多码已确认全部保留；同课程按文字累计熟练度，不同课程进度独立。
