# 打字游戏需求

更新时间：2026-10-30。状态：业务规则已确认，第 6 节列出待原型验证内容；尚未实现或验收。

## 1. 定位与课程

- 使用下落消除玩法，与普通分级练习分开，不采用逐题指定作答方式。
- 支持一级至四级、词组及生词本课程，包含对应的补充词库内容。
- 游戏独立随机出题，不改变普通练习的覆盖、练习组和熟练进度。
- 首版不包含闯关、生命值、排行榜、额外积分公式或历史趋势功能。

## 2. 自由消除与循环

- 文字或词组作为目标从上方下落，用户通过系统输入法提交文字。
- 提交文字与屏幕任一目标完全相同即消除，无需点击或指定目标，不限制实际输入编码。
- 屏幕上不同时出现文字完全相同的目标，即使它们对应不同编码。
- 成功消除后从当前课程随机补入新目标。
- 课程内容不足时减少目标数量，不通过重复显示相同文字填满屏幕。
- 目标落底后重新从上方出现，不记漏题、不扣分，不因落底结束游戏。
- 提交文字未匹配任何目标时，记一次错误，清空输入，目标继续移动；不推定用户意图，不展示某个目标的答案。
- 空格和空提交忽略，不按普通练习的空格跳过规则处理。
- 词库修改删除后，当前目标仍有有效课程来源则保留并更新编码提示，否则移除并补题，不计错误、不回退已完成成绩；保持同屏文字不重复和内容不足减少目标的规则。

### 输入提交边界（已确认）

- 每次输入法最终提交只作为一个完整答案，与一个完整目标匹配；组合输入及候选词选择过程不判定。
- 一次提交不拆分消除多个目标。例如屏幕有“学习”和“方法”，提交“学习方法”记一次错误，不消除这两个目标。
- 词组须一次完整提交，不逐字累积；实际提交的英文、数字、标点无匹配时按一次错误处理，输入法选字按键不单独计为提交。
- 游戏作答区域不接受粘贴，不消除目标、不记错误或提交次数，简短提示“请使用输入法作答”；不影响托盘生词添加文本框粘贴。

## 3. 编码提示

- 鼠标悬停目标时显示编码，移开隐藏。
- 查看提示不算错误，也不阻止继续游戏。
- 悬停时暂停该目标移动，移开后继续；不暂停整局或其他目标。
- 分级课程提示该课程编码，生词课程提示全部对应编码。

## 4. 难度与结束

- 提供简单、普通、困难三档，区别在移动速度和同时显示的目标数量。
- 同一局内不自动加速。
- 支持 1～5 分钟限时及主动暂停，到时结束并展示本次成绩。
- 暂停时停止计时、目标移动和作答，保留画面；切换窗口或最小化时自动暂停。
- 各档具体参数留到原型验证；开始倒计时 3 秒，暂停恢复、中途结束、关闭到托盘及退出重启行为见 [配置与会话规则](settings-and-session.md)。暂停保留目标位置并丢弃未提交输入，点击继续立即恢复，不重新倒计时。

## 5. 成绩

- 展示消除题数、正确字数、错误提交次数、正确率和每分钟正确字数，暂不设置额外积分。
- 正确率＝成功消除次数 ÷ 非空文字提交次数；空格和空提交不纳入分母。
- 题数和字数分别统计，例如成功消除一个四字词组计 1 题、4 个正确字。
- 每分钟正确字数按不含暂停的实际游戏时间计算。
- 无提交时正确率显示“—”，速度为 0；到时未提交输入不计成绩。

## 6. 待原型验证

- 目标避让及从顶部空闲位置重入的具体布局仍待原型验证，不宣称已解决重叠问题。
- 难度的具体数量与速度、单字和词组的时长适配留到原型验证，尚未确定参数。

## 7. 后续验收检查点

以下为已确认规则对应的待执行检查，不代表验证通过：

- 提交任一屏幕目标文字时仅消除匹配目标，并随机补题，屏幕同文字不重复。
- 落底目标继续循环，不增加错误、漏题或扣分。
- 无匹配文字记一次错误并清空输入；空格、空提交不增加错误或提交次数。
- 悬停显示编码，移开隐藏，查看不增加错误。
- 五类及生词课程可选，包含补充条目；游戏不改变普通练习进度。
- 三档难度可选、局内不自动加速，限时结束显示已确认的成绩指标。
- 暂停停止计时、移动和作答，失焦或最小化自动暂停；悬停仅暂停该目标。
- 少量内容减少目标数量，无提交正确率显示“—”，到时未提交内容不计成绩。
- 一次提交仅匹配一个完整目标，不拆分跨目标答案；组合输入不提前计错，粘贴不改变作答统计。
