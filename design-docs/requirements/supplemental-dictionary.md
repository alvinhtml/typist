# 补充词库需求

更新时间：2026-10-30。状态：以下规则已确认，阶段 2 已实现并完成本机业务检查，平台和活动练习联调边界见文末。

## 1. 目的与入口

- 设置中心提供“补充词库”，用于补充内置词库没有收录的文字、词组或编码。
- 用户逐条手动填写文字、编码、分类后提交。
- 分类包含一级简码、二级简码、三级简码、四级及词组五类，与内置五类课程对应。
- 补充词库维护识别与练习的数据来源；托盘仅按词库识别并添加生词，不提供临时补录编码的流程。
- 补充词库与生词本是不同职责；新增补充词条不自动加入生词本。

## 2. 去重与编码

- 在内置词库和补充词库合并范围内，统一按“文字＋编码”去重，完全相同则忽略添加；分类不额外构成去重键。
- 同文字不同编码允许保留；同编码不同文字不因编码相同而被忽略。
- 保留用户提交的编码，不由系统自行推导或改写。
- 文字不能为空，不能包含空白或标点；一级至四级要求单字，编码分别为 1～4 位，词组至少两个字，编码 1～4 位。
- 编码仅允许英文字母，去除首尾空白并转小写；只检查格式，不声称编码正确。此规范适用于用户提交及文件导入，不回写内置数据。

## 3. 本地保存与合并使用

- 内置 `data/level1.csv` 至 `data/level5.csv` 保持原样，不直接追加或修改。
- 补充词库独立保存在本机用户数据目录，离线使用；具体文件格式与目录结构留待技术设计。
- 使用时按分类合并读取内置与补充词库；重复的文字与编码不产生重复条目。
- 合并后的词库同时用于托盘文本识别、生词取码及对应课程练习。
- 补充条目参与对应分类课程，沿用已确认的练习规则；不因此重置原有学习进度。
- 保存后立即用于文本识别和覆盖统计；普通练习在下一轮补位纳入新题，不打断当前题。
- 总题数按当前有效文字计算，新增文字为未覆盖，退出课程的文字从覆盖及熟练统计中移除，其他文字状态不变。

## 4. 与生词添加的关系

- 生词识别严格匹配合并词库，仍遵循从左到右最长词组优先、单字兜底。
- 合并词库无法匹配的内容不加入生词本，提示未识别内容；用户可另行到设置中心补充词库。
- 未收录的完整词组若含可识别单字或短词，仍按现有拆分规则添加可识别部分，不自动创建该完整词组。
- 补充条目在后续识别中可被匹配；同一文字存在多个不同编码时，生词取码保留全部不同原编码。
- 生词本与补充词库分别提供 CSV 导入导出，均不携带学习进度；跨设备先导入补充词库，再导入生词本，见 [导入导出需求](data-exchange.md)。

## 5. 词条管理（已确认）

- 补充词条支持单条、批量删除，以及修改编码与分类。
- 不允许修改或删除内置词库条目。

### 5.1 删除与生词同步

- 删除补充条目后，以内置与补充词库合并后的最终结果判断该条目是否仍有效。
- 对已无词库来源的“文字＋编码”组合，同步从已有生词本删除该组合，不按文字一并删除其他编码。
- 内置词库仍含相同组合时保留对应生词；同文字还有其他有效编码时保留生词及其余编码，仅在全部编码都不存在时删除整个生词。

### 5.2 当前练习组与记录

- 变更后，文字仍属于当前课程时保留题目，更新可展示的编码；已不属于当前课程时立即移出练习组。
- 如果移除的正是当前题，取消该题并切换下一题，不计答错或跳过。
- 移除留下的空位在下一轮按既有选题规则补入，不改变其他题的进度。
- 课程已无可练内容时停止练习并提示，保留已完成作答的本次成绩。
- 已完成作答的本次统计不因删除而重算。
- 熟练记录按课程与文字处理：仅在文字退出对应课程时清除该课程中该文字的记录，其他课程和文字不受影响。
- 生词课程也按其最终有效文字集合处理；仅删除部分编码而文字仍保留时，不清除该文字的熟练记录。

### 5.3 修改编码或分类

- 修改视为移除旧组合、添加新组合，并继续遵守统一去重规则。
- 将修改作为一次完整变更，按最终词库和课程归属判断生词、练习组及进度的影响，不在中间移除步骤触发误删。
- 仅修改编码而文字仍属于原课程时，不因编码变化清除按文字保存的熟练记录；改变分类后，文字若退出原课程，则按退出课程规则处理。
- 修改编码时，已有生词本中对应的旧“文字＋编码”组合自动替换为该文字与新编码的组合，其他编码不受影响；替换后继续按文字与编码去重，新组合已存在则合并为一条。
- 替换不重置仍有效文字的学习进度；未收录旧组合时，不因此自动创建新的生词。
- 本规则针对修改引起的生词同步，不改变内置词库或其他词库来源。修改后组合已存在时不生成重复条目，提示“已存在，已合并”，仍完成旧编码到新编码的生词同步；保留已有组合的分类。
- 游戏中目标仍有有效课程来源时保留并更新提示，否则移除并补入其他目标，不计错误、不回退已完成成绩；内容不足或为空时按实际可用内容处理。

## 6. 后续验收检查点

以下为待执行检查，不代表验证通过：

- 五类条目均可逐条提交；对应分类已存在的相同文字与编码被忽略，同字异码可保留。
- 补充操作不改变内置 CSV，补充数据在本机持久保存，应用重启后仍可读取。
- 补充条目可用于后续托盘识别、生词取码及对应课程练习。
- 无法识别的内容不会通过托盘临时手填编码加入；最长匹配和单字兜底继续有效。
- 已有生词与课程学习进度不会因补充条目而被整体重置。
- 删除仅同步移除失去词库来源的生词编码组合，内置仍有效的组合和同字其他编码保留。
- 移除当前题不计错误，下一轮补位；空课程停止，已完成成绩不回退。
- 修改按最终结果处理，不因中间移除步骤误删生词或清除仍有效的文字熟练度。
- 修改编码自动替换已有生词中的对应旧组合，新组合重复时合并，不影响其他编码或仍有效的学习进度。
