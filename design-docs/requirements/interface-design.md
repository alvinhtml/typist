# 桌面界面视觉规范

2026-10-31。用户已确认目标：参考 Linear 的层次与一致性、Raycast 的桌面交互品质，升级全部页面并精心支持明暗主题。以下为本轮实现方案，具体视觉效果待用户体验确认；不将参考产品界面复制为需求。

## 视觉系统

- 浅色：冷白画布 `#F7F8FA`、白色面板、石墨正文 `#242930`，延续已确认的绿色 `#237A60`。
- 深色：炭灰画布 `#141619`、面板 `#1B1E23`、浮层 `#22262C`、正文 `#EAEDF1`，强调色提升亮度至 `#72D4B0`。
- 背景、面板、浮层、输入控件、分隔线、次级文本、成功、错误、焦点与遮罩均使用语义变量，禁止用单一反色模拟深色。
- 系统中文/西文字体，数字采用等宽和 tabular-nums；练习题目保留原有楷体与系统回退。正文与操作为13px左右；标题19～28px，底部统计主值15px、辅助信息11～12px，游戏当前输入16px。
- 以4px为主的间距、6～14px圆角；细边框与轻阴影表示层次。强调色集中于主要操作、当前题、进度及反馈。

## 页面与交互

- 首页保持无侧栏的三入口结构，增加轻量编号、图标和说明层级，管理入口次要呈现；品牌区与主题入口保持安静。
- 练习和游戏共用紧凑操作条与底部成绩样式。练习不显示输入框外观；游戏隐藏输入节点、底部纯文本显示字母，除顶底栏外全部为游戏空间。
- 2026-10-31 用户调整：分级练习及游戏底部统计压缩为薄状态条，标签、数值、单位和详情横向排列，覆盖/熟练进度条也在同一行。标准高度约46px；窄窗口允许按统计项整体换行，不遮挡或删除指标。游戏当前输入与标签横向排列，保持点击统计区域恢复输入的行为。
- 用户反馈灰底上的白色卡片不协调：生词本、添加文本、设置及文本小窗口取消大卡片底色、外框、圆角和阴影，直接在页面画布上排布内容，分区以间距及细分隔线区分。输入控件采用同色系浅层底色，次要按钮透明。管理页使用清晰的标题、行分隔与一致控件；搜索框弱化底色，编码使用等宽标签。删除操作用错误语义色，禁用状态仍可区分。
- 设置页按用户参考图采用页面标题与简介、左侧分区说明、右侧宽表单。标签在控件上方；练习偏好与补充词库相关字段分两列，分类及说明跨列，保存与编辑操作靠内容区左侧。提供现有主题功能的颜色模式入口，即时生效；练习偏好仍需保存并从下一局生效。各区内容左右边界统一，以留白和细线分隔。800px及以下分区说明移到上方，480px及以下字段改单列；缩放时自然纵向滚动。CSV报告留在对应操作区域，不通过基于内容的CSS选择器决定布局。
- hover、pressed、disabled、focus-visible 均有明确反馈；确认框保留键盘焦点约束及 Escape 取消。轻量动效不延迟导航，系统减少动态效果时禁用。
- 不引入全局作答监听，不改变编码判定、词库、学习进度、会话或退出规则。
- 生词本采用紧凑横向列表，文字后一个浅色等宽标签直接容纳全部编码，不使用展开或编码级勾选；保留文字级选择与删除。工具栏提供文字/编码搜索和批量删除，标题显示总文字数，选中行使用轻量强调底色，多码和长词允许换行且不遮挡删除按钮。

## 主题

- 顶部主题按钮提供跟随系统、浅色、深色；首次默认跟随系统，立即响应系统外观变化。
- 主题仅是渲染界面的外观偏好，保存到本机 localStorage `typist.appearance`；主窗口与文本小窗口通过 storage 事件同步。读取异常时回退到系统主题，不影响业务使用。
- 不增加依赖、网络字体、IPC 或数据库迁移。系统窗口装饰和原生对话框继续由系统/Electron 管理，不等同于已验证手动主题能控制原生外观。

## 检查边界

关键文本/背景组合目标对比度至少4.5:1；必须检查明暗页面、实际词条、练习运行态、键盘输入、窄窗口及缩放，不能以颜色检测替代全界面可访问性审计。实际结果见 [验证记录](../../test-results/desktop-ui-report.md)。Windows字体、原生菜单/对话框及真人长时间体验待实机确认。
