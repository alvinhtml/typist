# 配置、暂停恢复与退出需求

更新时间：2026-10-31。状态：以下规则已确认；阶段 3 已接普通/生词练习，游戏与跨平台人工验收仍待后续完成。

## 1. 配置

| 项目 | 规则 |
| --- | --- |
| 练习组大小 | 默认 20 题，可配置为 5～100 题 |
| 连续正确阈值 | 默认 3 次，可配置为 1～10 次 |
| 配置入口与范围 | 设置中心统一配置，所有课程共用；各课程学习进度独立 |
| 练习或游戏时长 | 开始前选择 1～5 分钟，记住上次选择 |
| 游戏难度 | 开始前选择简单、普通或困难，记住上次选择 |
| 开始倒计时 | 固定 3 秒，再正式计时 |

练习组大小与连续正确阈值的修改在下次开始练习时生效，不改变正在进行或暂停中的一局：

- 扩大组：按 [练习补位规则](practice.md) 增加题目。
- 缩小组：在新大小内优先保留未熟练题，其余退出当前组但保留学习记录。
- 修改阈值：保留已有连续正确次数，按新阈值判断；已经退出组的暂时熟练题不追溯重算。
- 可用内容不足配置组大小时仍按实际内容缩小组，不重复凑题。

## 2. 暂停与恢复

- 普通练习、生词练习和游戏均允许主动暂停；切换窗口、最小化、打开应用内其他页面或设置中心时暂停当前一局。
- 暂停停止计时与作答，游戏同时停止所有目标移动；画面不隐藏。
- 保留当前题、题序和已完成成绩，游戏还保留目标位置。
- 尚未提交的输入作废，不计错误；恢复后重新输入，不补判暂停期间或失焦过程中产生的未提交内容。
- 手动或自动暂停后，均需点击“继续”，不自动恢复；恢复时不再倒计时，立即从剩余时间继续。
- 有效时长不含暂停，速度按有效时长计算。

## 3. 离开页面与结束本次

| 操作 | 行为 |
| --- | --- |
| 离开练习或游戏页 | 保持当前一局暂停，返回后可点击继续 |
| 点击“结束本次” | 结束并展示已完成部分成绩，速度按实际有效时间计算 |
| 暂停中切换课程或重新开始 | 提示将结束当前一局，确认后执行 |
| 关闭主窗口 | 收到托盘，当前一局保持暂停 |
| 托盘选择退出应用 | 有未结束的一局时确认退出，保存已完成的学习进度 |

- 中途结束不撤销已完成作答产生的覆盖、错误和熟练记录；未提交内容不计成绩。
- 重启应用后只恢复已保存的学习进度，不恢复未结束的一局、剩余时间、游戏目标位置或该局现场。
- 学习进度保留不等于新增历史成绩功能，历史成绩存储仍不在已确认范围内。

## 4. 后续验收检查点

以下为待执行检查，不代表验证通过：

- 默认值、允许范围、全课程共用配置及上次选择记忆符合约定。
- 修改配置不改变当前或暂停的一局，下次开局按扩缩组及阈值规则处理，已有学习记录不整体重置。
- 主动暂停、失焦、最小化及页面切换均停止计时和作答，游戏目标冻结；恢复必须点击继续，不重新倒计时。
- 暂停丢弃未提交输入但不计错，已完成成绩与目标位置保持。
- 离开页面可返回继续，主动结束显示实际成绩，切换课程或重新开始先确认。
- 关闭窗口收到托盘；退出应用按未结束状态确认；重启只恢复学习进度，不恢复一局现场。
