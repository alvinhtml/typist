# 太空打字防御战开发计划

2026-11-12。状态：战斗规则、战场素材与回归已实现，参数试玩及跨平台人工验收待完成。

## 依据与边界

- 行为和验收以[正式游戏需求](../../requirements/typing-game.md)及[配置与会话](../../requirements/settings-and-session.md)为准；使用[整合素材包 V1](../../../src/README.md)。
- 在现有入口原位替换。复用 `src/shared/answer-input.ts`、`src/shared/session.ts`、课程和词库同步、计时暂停、活动局确认及已有时长记忆。
- 现有游戏页和设置中心均有难度选择。新版移除两处难度选择，保留其余适用设置；旧难度字段继续兼容读取，游戏采用单一配置。沿用现有设置契约及 SQLite 结构。
- 变更集中在游戏规则、战场与相关设置 UI。成绩留在本局，维持现有词库、学习进度及 Electron 安全边界。

## 实施顺序

1. **可玩规则。** 在 `src/shared/game.ts` 实现按节奏生成、自由选敌、1～3 HP、普通弹及智能穿甲弹、防线和结算。采用现有可注入时钟和随机源验证规则；提交按顺序立即更新战斗状态，视图消费射击和命中结果。
2. **战场和特效。** 在 `src/renderer/GamePanel.vue` 接入飞船、背景、文字核心、防线和战斗特效。固定玩家飞船位置，按攻击目标转向。字词、HP 和 HUD 动态绘制；动画和资源加载独立于输入与结算。按实际显示尺寸生成素材版本，验证透明边缘、锚点、长词、高 DPI 和窄窗口下的可读性。
3. **回归与试玩。** 更新 `tests/game.test.cjs` 和 `tests/game-smoke.cjs`。保留编码、暂停、词库变动与练习隔离的回归覆盖；将旧版三档难度、悬停和落底循环断言改为新版对应行为。覆盖同码顺序、连续输入、伤害和弹药、突破、暂停和两种结算边界。执行 `npm test`、`npm run smoke:game`，记录实际结果。试玩调生成节奏、速度和同屏密度，并记录实机视觉及跨平台验证状态。

## 2026-11-12 实施与验证

- 规则按有效时间处理生成、突破和限时事件，提交同步结算伤害、穿甲弹、得分和连击。初版采用 2.4 秒生成间隔与 4 条独占航道。飞船及文字核心使用长边 288px 的显示版本。
- `npm test` 通过类型检查、构建和 52 项单测，覆盖同码顺序、多码、连续命中、弹药、突破、冻结和两种自动结算。[单测日志](../../../test-results/space-typing-defense-test.log)
- `npm run smoke:game` 在受限沙箱内完成构建，Electron 启动时收到 SIGABRT。同一命令在 macOS arm64 原生桌面最终以退出码 0 通过，覆盖设置与时长记忆、键盘焦点、两组连续四码、暂停和离页、760px 布局、跨窗口删除存活目标及练习进度隔离。[沙箱日志](../../../test-results/space-typing-defense-smoke-sandbox.log) · [桌面日志](../../../test-results/space-typing-defense-smoke-native.log) · [窄窗口词组截图](../../../test-results/typist-space-game-vocabulary.png)
- 人工验收仍待完成，见[待验证事项](../../state/issues.md#太空打字防御战待验证2026-11-12)。
