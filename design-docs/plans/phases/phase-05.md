# 阶段 5：下落消除游戏

2026-10-31。状态：用户已确认编码规则；实现与本机自动检查交付，人工及双平台验收待补。

## 依据与范围

依照 roadmap 阶段 5、requirements/typing-game.md、settings-and-session.md。复用课程分页、设置记忆、Session计时、活动局退出确认和词库通知；游戏仅保留内存成绩，不调用 saveLearning，不迁移数据库。

## 2026-10-31 用户确认规则

1. 同一编码匹配多个目标：仅消除位置最靠近底部的目标；位置相同时按出现顺序选择。
2. 提交时机：1～3位编码按空格提交，4位自动提交；短码即使匹配也等待空格，避免提前消除挡住长码。空缓冲空格忽略，非空缓冲空格提交参与判定。
3. 字母转小写，退格删除；粘贴、拖入及中文组合输入不判定。其他非法字符忽略；暂停清空未提交编码不计错。

以上三项均已由用户明确确认。

## 实施与验收

确认后先实现可注入时钟和随机源的纯游戏模型，再接页面与输入。独立随机目标、同屏文字去重、落底循环、消除补题、悬停单目标冻结、整局暂停与成绩按已确认需求执行。复用阶段0实验参数开展布局验证，数量、速度与长词避让以实际结果记录，不宣称原型参数已验收。

联调普通练习与游戏切换，保证主窗口单活动局、切课重开确认、离页暂停、词库最终集合更新及失效目标取消。验证游戏前后普通练习学习记录不变。

确定性测试覆盖同码选择、长短码提交、暂停/到时边界、落底不计错、悬停与全局冻结、无提交成绩、空课程及不足目标；Electron覆盖设置记忆、跨窗口词库变更和统一会话生命周期。更新正式需求、架构、状态与实际验证报告后方可标记实现交付。
