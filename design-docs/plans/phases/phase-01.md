# 阶段 1：工程与桌面基础

2026-10-31。用户已要求按路线图开始阶段 1；沿用阶段 0 已确认架构，不扩展阶段 2～5 业务。

## 执行范围

1. 根目录正式 Electron / Vue / TypeScript 工程，保留独立原型。
2. 主进程独占 SQLite、沙箱 preload 固定接口、导航与统一错误提示。
3. 初始化设计中的持久表；设置真实读写、revision / requestId 事务保护；学习数据表读取与重启验证。业务 saveLearning 留阶段 3，避免绕过课程有效性检查。
4. 主/文本窗口单实例、托盘恢复与退出；关闭/最小化/失焦通知暂停。
5. 仅内存公共会话状态机，设置快照、倒计时、暂停与 generation；后续业务接入前不得开放虚假练习。
6. Forge 打包资源与本机运行验证；Windows 实机延期，不作为通过。

## 验证

- 类型检查、生产构建、存储和会话自动测试。
- Electron 实际窗口、preload、跨窗口通知、安全边界和生命周期冒烟。
- 内置 CSV SHA-256 与 Git 基线比较。
- 本机打包与包内资源/数据库检查；真实托盘点击、Windows 和其他 macOS 发行范围单独记录。

实际结果见 [阶段报告](../../../test-results/phase1-report.md)。本阶段尚未达到全部双平台验收，不自动进入阶段 2。
