# 阶段 3 整改：直接编码输入

2026-10-31。状态：整改规则已确认，R1/R2 实现和 R3 本机自动验证完成；真实键盘与平台验收待补，详见 [独立报告](../../validation/phase3-code-input-report.md)。

## 1. 原因与权威范围

用户实测认为按输入法上屏文字判定不适合编码练习，已确认改为直接输入字母，与当前题目的词库编码完全比较。

- 本文替代阶段 3 旧的文字输入、composition 提交和 50ms 缓冲约定；旧报告与原型保留为历史证据，不继续作为现行需求或新方案通过依据。
- 本轮已按本文实施编码整改。阶段 4 暂不进入，先完成整改及回归。
- 不修改内置 data、不升级依赖、不擅自迁移数据库；保留已有学习进度、练习组、覆盖与熟练记录，不自动清空。旧记录来自文字判定，不表示编码已熟练。
- 生词文本添加、补充词库及 CSV 字段、按课程文字统计的方式不改变。只有作答输入和正确性判定改为编码。

## 2. 已确认的练习规则

| 课程 | 自动判定长度 | 有效答案 |
| --- | --- | --- |
| 一级 | 1 个字母 | 当前题在一级课程的编码 |
| 二级 | 2 个字母 | 当前题在二级课程的编码 |
| 三级 | 3 个字母 | 当前题在三级课程的编码 |
| 四级 | 4 个字母 | 当前题在四级课程的编码 |
| 词组 | 满 4 码自动判定，短码空格提交 | 当前题在词组课程的编码 |
| 生词专项 | 满 4 码自动判定，短码空格提交 | 当前生词全部有效编码 |

- 同题在有效范围有多个编码时，任一个完全相同即正确；不反向查码选字，不将编码与汉字字面比较。
- 词组/生词即使缓冲命中短码，也不提前判对，等待空格或满四码，避免截断长码。
- 编码逐字母累计，大小写归一为小写；数字和标点忽略，不计错、不推进，不加入编码。
- 未达到自动长度时可退格修改；有编码按空格立即提交，不完整或不匹配计错并推进；无编码按空格为跳过计错。
- 满码判定并清空缓冲，后续新字母归下一题；一次提交最多完成一道题，不重复判定。
- 正确下方显示绿色题目文字；错误下方显示红色实际输入编码，上方题目下显示正确编码；空格跳过结果留空。编码不转换成错误汉字。
- 作答拒绝粘贴、拖入，提示使用英文状态逐键输入编码；托盘中文文本添加正常工作。
- 暂停、当前题失效、结束和切题清空未提交编码，不计错；已完整提交的答案仍按有效时间和事务结果计分。
- 建议英文输入状态，不再接受中文上屏文字作为答案。中文输入法误开启时的检测、提示和拦截能力需实测，不使用全局键盘钩子或擅自强制切换系统输入法。

## 3. 实施任务及顺序

### R1：模型与输入层

- 检查 src/shared/answer-input.ts、practice.ts、session.ts 和 PracticePanel.vue 的调用关系及现有未提交改动，保留用户和其他任务的改动。
- 将模型正确性由 answer===word 改为当前题有效 codes 包含规范化编码；空格跳过独立表达，避免与普通编码混淆。
- 输入缓冲与练习业务判定分开，按课程提供长度及提交策略；不再通过中文 compositionend 或最终 input 上屏来提交答案。
- 正式作答移除 50ms 延迟提交/flush、尾随 composition 去重等旧路径；保留必要的输入代次、失效取消与粘贴防护，避免事件重复派发。
- 仅在作答区启用，不截获设置、托盘或其他输入框；快捷键、退格、焦点和中文组合状态需明确处理并验证。

### R2：界面与一致性

- 修改说明、占位符、提示为直接输入编码；实时展示未提交字母，错误结果显示编码，正确结果仍显示文字。
- 保留现有排版、统计口径、倒计时、分组复习、持久化事务及保存失败不计分的规则。
- 复查连续快速满码输入与异步 saveLearning 队列：后续编码不得因前题尚未提交到存储而匹配错误题目；保证作答顺序、一次计分、失败可恢复。
- 复查题目变更、退出/暂停、到时与键盘事件交错；不沿用旧 composition 缓冲解决编码边界，不吞掉已经完整提交的有效答案。

### R3：测试与验收

- 更新 tests/answer-input.test.cjs、practice.test.cjs、practice-smoke.cjs；检查现有测试调用，不只让 UI 跳过旧断言。
- 模型检查：各级长度、仅当前课程编码、多码、错码、提前空格、空格跳过、词组/生词短码需确认、长码不被短码截断。
- 输入检查：大小写、退格、非法字符、粘贴/拖入、按键自动重复风险、焦点丢失、暂停恢复与旧回调失效、快速连续输入。
- 集成检查：存储失败/冲突不污染计分、截止边界、删改当前题、原学习进度保留、分组复习和统计无回归。
- 按项目现有命令执行 typecheck、测试与构建，并运行基础、业务及练习 Electron 冒烟；记录退出码、实际环境和失败处理，不宣称未执行的检查通过。
- macOS 实际键盘验证各级自动判定、短码、退格、暂停和中文输入法误开启；Windows 实机仍按既有延期边界记录未验证，不冒充通过。
- 用隔离测试数据检查持久化与回归，实际用户数据库不得清空。
