# 阶段 3：普通与生词专项练习

2026-10-31。用户明确要求继续下一阶段，开发前已提交阶段 2：a6b9695。

沿用练习/会话需求、现有 Session、SQLite v1 和已设计 saveLearning 接口，不改变依赖或数据结构。

1. 独立确定性练习模型：按课程文字、持久组与学习记录、每轮洗牌、阈值替换、累计4新/1复习、复习排序、覆盖和本局统计。
2. saveLearning 固定接口：事务保存课程记录及组/cursor，验证最终课程归属、revision、幂等；失败不显示成功。
3. 主窗口保留内存局，课程/时长、3秒倒计时、对齐反馈和自适应题格、暂停/离页/恢复/结果；生词沿用同一模型。
4. 移植原型输入边界，拒绝粘贴/拖入、组合提交去重、暂停代次失效和50ms缓冲；主窗口原生失焦与最小化通知配合，候选窗行为仍需真实输入法复验。
5. 完整词库变更立即取消失效当前题、更新提示和覆盖，下一轮补位；保存失败、冲突及倒计时边界测试。
6. 学习记录/组重启恢复，本局不持久化；切课/重新开始确认，活动局退出确认；CSV闭环仍留阶段4。

验证：确定性时间和随机源测试，存储失败/幂等/重启检查，真实Electron的合成输入和双窗口删除联调，截图检查。操作系统真实输入法人工验证不能由合成事件替代。
