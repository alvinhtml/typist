# 当前状态

游戏输入提示改为按键面板上方的右对齐纯文字，使用轻微文字阴影保持战场上的可读性。构建及 54 项单测通过。

## 游戏切回英文后恢复输入

共用作答监听按当前按键的输入法标记过滤组合事件；切换输入源缺少组合结束事件时，后续英文按键可立即作答。构建、54 项单测及 macOS 游戏冒烟通过，冒烟模拟了组合开始后直接恢复英文按键。真实输入法切换仍待实机复测。

## 战斗 HUD 细节

准备、暂停和结算共用的任务卡改用连续切角边框，移除原边框素材的四角装饰点。构建、53 项单测及 macOS 游戏冒烟通过，已复核准备页与 Esc 暂停菜单截图。

顶部移除公共衬底并压低独立状态框。底角移除穿甲弹与当前输入的可见标题，保留库存和键位，面板随内容收紧。构建、53 项单测及 macOS 游戏冒烟通过，已复核 760px 截图。

顶部装甲分隔、计时数字和 Esc 键帽提高辨识度；防线耐久按健康、受损、危急显示绿、琥珀、红。底角补充穿甲弹与输入键位的材质细节，作答框聚焦时输入面板亮起微光。构建、53 项单测及 macOS 游戏冒烟通过，已检查默认和 760px 窄窗口截图。

## 太空打字防御战音频

接入已确认的游戏音效和 16 秒合成器循环背景音乐。设置中心「游戏声音」可独立调整音乐和音效，默认分别为 35% 和 65%，使用本机界面偏好存储。倒计时提示按实际秒数播放，命中声与弹道时间同步，游戏暂停时暂停音乐，结算时停止循环。

构建和 53 项单测通过。macOS Electron 游戏冒烟通过，包含音量滑块独立写入及 0% 保存检查。已检查 WAV 参数、峰值和循环边界的采样连续性。实际听感与 Windows 播放待验证。

## 游戏按同屏题量补充敌机

开局敌机沿飞行方向按 0.5 秒飞行距离前后错开。构建、53 项单测和 macOS 游戏冒烟通过，实际间距待试玩确认。

开局最多出现 6 个不同目标，之后同屏少于 3 个时立即补到 3 个。横向位置在战场内随机选取，优先与附近敌机拉开距离。构建、53 项单测和 macOS Electron 游戏冒烟通过。一级简码与词组的实际节奏及窄窗口长词重叠情况待试玩确认。
