## 原型参数与设计结论

窗口实验宽度 1100 / 760 / 480，高 780；小窗口允许纵向滚动。添加面板最大 420 px；正式主窗口建议最小 760×640，游戏长词优先在宽窗口使用。这只是布局设计值，不扩展平台支持承诺。

游戏参数为简单 3 个/24 px/s、普通 5 个/40 px/s、困难 7 个/60 px/s，画布高 420 px。以单目标独立列避免横向重叠，长词换行；原型验证了数量、移动和暂停可行性。三档主观难度与小词库/超长词的最终调优属于游戏阶段，不能宣称体验已经定稿。

## 已知限制与阶段边界

- 50 ms 输入缓冲在用户环境通过暂停复测，但并非所有系统事件时序保证；缓冲内暂停会取消刚刚选中的文字。保留为正式实现前需评估的输入边界，不删除失败证据。
- 用户人工日志未填写系统/输入法版本；本机环境可记录，但不能推断日志对应的输入法品牌。
- Windows 10、最低 macOS 与 Intel 实机覆盖未完成。Windows 实机由用户明确延期；其他目标范围不自行承诺。
- node:sqlite 实验可用，但正式驱动封装、迁移恢复、磁盘满、崩溃恢复、打包后运行仍需工程阶段验证。
- data/words.csv 为额外单条文件，需求指定课程资源为 level1～5，保留该文件而不作为第六课程。

本轮设计与最小原型交付已完成，不能标为所有平台/业务验收完成。阶段 0 保留输入边界风险与发行环境待验证项；阶段 1 尚未启动。
