## 实现

- answer-input.ts 在作答框内用 keydown 同步累计字母；一级至四级满 1～4 码提交，词组/生词短码空格提交、四码自动提交。不提前匹配短码，不使用中文 input/compositionend 作答，无 50ms 提交定时器、尾随去重或 flush。
- 大小写归一、退格、非法字符忽略、自动重复忽略；保留系统快捷键和 Tab 焦点导航。粘贴/拖入拒绝并提示；composition / isComposing / keyCode 229 拦截并提示英文输入。只能根据浏览器提供的事件识别组合状态，不保证识别全部输入法。
- Practice.answer 使用当前课程 codes 完全匹配，null 明确表示空格跳过；正确反馈显示绿色文字，错误显示输入编码及正确码，跳过下方留空。
- 完整提交在事件接收时检查有效时钟并进入串行队列，依次按上一成功模型判定/保存；暂停或截止只取消未提交缓冲，不取消已完整提交答案。保存成功后更新成绩，失败暂停、恢复存储状态并取消后续排队答案；外部课程变更取消旧排队答案并重载。
- 学习进度、分组/复习、统计、saveLearning 事务和 SQLite v1 保留，无数据库迁移或清空。内置 data 无差异，未升级依赖。开发前已有未提交改动保留，没有重置或提交这些改动。
