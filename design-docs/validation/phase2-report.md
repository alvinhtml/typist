## 交付

- 五类 CSV 只读加载，按文字/编码组合去重并保留不同分类来源；按课程文字聚合，编码全部保留；固定 IPC 分页查询。
- Trie 从左到右最长词组优先，单字兜底，不重复词组内部单字、不跨标点空白；未知内容去重反馈。
- 主页面与托盘文本窗口共用手动添加：不因输入/粘贴自动提交，结果只列本次新增编码，按重复出现的组合计数；继续添加清空上一批。
- 生词按文字聚合，可展开编码，按编码/整字单条或批量删除；仅删除最后编码时清理生词课程记录。
- 设置中心逐条补充文字/编码/分类，支持编码和分类修改、单条/批量删除、格式校验、编码标准化和重复合并；新增补充不自动加入生词。
- 主进程事务协调补充变更、生词改码替换/合并、最终词库校验、课程记录和组清理、revision 与幂等结果。候选索引在提交前构建，提交后交换并通知；失败回滚，不广播成功。跨窗口收到通知重取快照。
