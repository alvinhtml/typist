# Typist 太空打字防御战 — 整合素材包 V1

此包整合此前三批素材，**未对素材重新绘制或提升画质**。`assets/game/` 下的文件可供 Codex 接入；`reference/` 仅为概念参考，禁止当作独立特效序列使用。

## 目录
- `assets/game/display/`：由 V1 飞船和文字核心缩小生成的显示版本，长边 288px。
- `assets/game/ships/`：玩家飞船和四类敌机，汉字由程序叠加。
- `assets/game/scene/hologram/`：四类文字核心；运行时绘制单字或词组，保持文字正向。
- `assets/game/scene/background/`：两张太空背景。
- `assets/game/scene/shield/`：防线状态和撞击帧。
- `assets/game/combat/`：普通/穿甲弹、命中火花、爆炸、烟雾、闪光、裂纹。
- `asset-inventory.json`：实际文件尺寸、Alpha 通道与 SHA-256 校验信息，以及原战斗动画配置。

## Codex 集成原则
1. 在现有 Typist 下落消除游戏位置原位替换，不新增游戏模式；保留现有五笔86编码规则、四码自动提交、短码空格提交、计时暂停与学习数据隔离。
2. 文字内容及血量是程序绘制层，绝不烘焙进飞船素材。单字/词组共用编码匹配与伤害逻辑。
3. 玩家飞船位置固定、机身自动转向；动画不得阻塞连续输入。普通弹扣1HP，穿甲弹按既定智能规则消耗。
4. 资源加载前根据 `asset-inventory.json` 验证文件存在；缩小到实际游戏尺寸后检查清晰度。
5. 请先审查现有游戏代码与 design-docs，列出需复用/替换的模块，再分阶段实施并测试。不得假定本素材包已通过实机视觉验收。

## 已知限制
- 此包仅做文件整合、基础格式/尺寸检查；尚未完成实机视觉效果、透明边缘质量、动画连贯性和性能验收。
- 某些素材的风格精细度可能不同，正式上线前需在实际画面中检查。
- `reference/` 中的概念拼版不是可直接使用的独立游戏素材。
