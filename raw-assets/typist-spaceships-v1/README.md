注意：敌机中央核心未嵌入任何汉字，文字、血条、引擎尾焰和受损动画需由游戏单独渲染。图片比例与核心位置各异，Codex 需按敌机类型配置显示尺寸与文字位置。

素材为首批静态美术，未包含旋转帧、受损帧或爆炸序列。
