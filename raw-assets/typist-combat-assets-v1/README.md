# Typist 战斗特效素材包 V1

包含可直接加载的透明 RGBA PNG 序列：普通子弹、穿甲弹、命中火花、小型爆炸、大型爆炸、受损烟雾与受击闪光，以及两级受损裂纹叠加层。

- `manifest.json` 提供帧数、帧尺寸、建议 FPS 和循环属性。
- 所有动画以文件夹内 `00.png` 开始顺序播放；无背景色，支持 Canvas 2D。
- 子弹素材默认朝上；由游戏运行时旋转到弹道方向。
- 裂纹、烟雾和闪光应叠加到敌机图片上，不替换敌机本体。
- 动画播放不应阻塞五笔编码输入与逻辑判定。
- 本包特效采用程序生成的游戏可用基础版本；附带 AI 生成的美术概念参考图，但概念图不是可直接使用的透明序列。
