# Typist 场景素材 V1

包含可直接加载的 PNG 文件：
- `hologram/core_*.png`：512×512，透明背景，**不含文字**；运行时在圆心叠加正向汉字或词组，文字不随飞船旋转。
- `background/*.png`：1920×1080，不透明太空背景。
- `shield/barrier_*.png`：1600×320，透明背景，正常/受损/危急三态。
- `shield/impact_00..07.png`：256×256，透明背景，按顺序播放的防线撞击动画（建议总时长 300–450ms）。

## 集成注意
1. 这些是程序生成的**首版可用基础素材**，不等同于前面 AI 绘制的高精度概念图；后续可继续美术精修。
2. 核心是可叠加的独立 UI 图层，不要将汉字写进 PNG；缩放时注意 1–4 字词组的可读性。
3. 防线素材放在画面底部，受损状态按基地耐久切换，撞击效果叠加播放。
4. 背景适合低速平移，注意不要遮挡文字。
