# 阶段 0 输入实验

运行：npm ci，然后 node node_modules/electron/install.js 下载 Electron 运行时，再 npm start。npm run smoke 执行合成事件冒烟检查；不能代替真实输入法。已生成 package-lock.json。

隔离实验，不实现业务、托盘或持久数据；Electron 44.2.0 为已批准实验版本，Vue 3.5.44、Vite 7.3.7、TypeScript 5.9.3，类型检查与构建已通过。Forge 为正式选定打包工具，本实验尚未加入打包。

填入系统版本/架构及输入法版本，逐项执行并导出 JSON：空格/数字/鼠标选字、完整词组、连续两次相同文字、英文数字标点、直接空格、退格、粘贴、拖放、组合时暂停/失焦/最小化、点击候选窗口、恢复后继续。普通和游戏模式分别检查。日志包含测试输入，请只使用测试文字。

预期：每个最终提交只出现一次判定；组合过程不判定；暂停后旧输入不判定；粘贴无判定；普通直接空格跳过，游戏忽略。当前策略是待实测假设：compositionend 延迟读取最终值，与 input 共用清空去重；可能存在平台事件顺序差异，必须保存失败日志，不能据代码宣布真实输入法通过。窗口 blur 当前直接暂停，候选窗若触发 blur 即记录为失败，后续依据真实证据调整。

## 给验收者

运行 npm start 后按左侧 1～9 步操作。每步先读“怎么做”和“应该看到”，再点击“开始本步”；“继续本步”不清空已有提交。系统版本、输入法版本不知道可以留空。每步选择符合预期/发现异常/暂不测试，最后导出验收记录。第 9 步只观察样例，不需输入；这不是最终业务页面验收。日志仅保留在本窗口，关闭前导出。

## 自主验证

`npm run phase0` 执行 Electron SQLite 临时实验、布局与游戏参数检查；`npm run layouts` 打开关键页面样例；`npm run smoke` 运行输入回归。实验不读取用户学习数据。结果与截图写入 test-results。
