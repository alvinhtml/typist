## 提案

- 暖白 #faf9f5、深墨 #202b38、强调绿 #237A60（用户于 2026-10-31 通过设计控制确认此次颜色调整，取代该稿原强调蓝）；系统界面字体，练习题使用本机楷体并提供中文字体回退，无网络字体。
- 首页三主入口居中，分级练习优先强调；生词本、添加文本、设置使用轻入口。游戏仅展示未实现状态。
- 练习顶部控制、中央题目和对齐反馈、底部五项统计；实时编码放当前题下方，细下划线标记当前题。上一轮默认收起。
- 首页移入上浮 5px、边缘蓝色与局部跟随光晕，按下缩放至 98%、点击波纹 450ms，导航不等待动画。支持键盘焦点及减少动态效果。
- 顶部预览控制可切换首页、分级/生词练习、运行/未开始/倒计时/暂停/空课程/保存失败/结束成绩及 430px 窄窗口；设计控制提供强调色、减少动态效果及长词组/罕见字示例。

## 范围与限制

仅展示与本地状态交互。统计、词库和反馈为示例；输入可显示字母和退格，不进行判题、持久化或真实会话恢复。管理页为辅助视觉示意，不代表完成其全量设计；文本小窗口入口不创建原生托盘窗口。课程切换确认等正式业务沿用现有规则，原型不实现完整业务。
